## 4. Manual Cron Triggers (20 routes)

All routes require header `Authorization: Bearer ${CRON_SECRET}`. Without it, Vercel/Edge returns 401.

```bash
export BASE=https://e2e-sandbox-check.preview.emergentagent.com
export CRON_SECRET=$(grep ^CRON_SECRET /app/frontend/.env | cut -d= -f2-)

for cron in \
  affiliate-digest affiliates analytics-snapshot auction-close \
  contract-shield faith-verse-rotation health-check holds \
  inventory-stale-sweep inventory-sync-full inventory-sync-priority \
  prequal-ibv-reminders prequal-message-delivery prequal-purge \
  prequal-sla-escalation prequal-stale-cleanup sessions sla-check \
  trust-check workflow-automation
do
  curl -s -o /dev/null -w "%{http_code}  $cron\n" \
    "$BASE/api/cron/$cron" -H "Authorization: Bearer $CRON_SECRET"
done
```

Last verification: **all 20 cron endpoints returned `200`**.

These three gates **remain open**. Each requires human action and must NOT be triggered from the sandbox.

## 8. Edge Cases & Reset Helpers

| Helper script (in `scripts/`)               | Purpose                                                                  |
|---------------------------------------------|--------------------------------------------------------------------------|
| `sandbox-totp.ts`                           | Print the current TOTP code for the seeded admin                         |
| `sandbox-reset-admin-totp.ts`               | Re-enroll admin TOTP with a freshly-generated sandbox secret              |
| `verify-marketcheck-skip.ts`                | Smoke MarketCheck adapter without writing to inventory                   |

```bash
# Re-enroll admin TOTP (when previous secret was encrypted with a stale key)
PREQUAL_ENCRYPTION_KEY=$(grep ^PREQUAL_ENCRYPTION_KEY .env.local | cut -d= -f2-) \
  npx tsx scripts/sandbox-reset-admin-totp.ts
```

### Common edge cases

- **Duplicate dealer application** → `409 DUPLICATE_APPLICATION`.
- **Expired dealer invitation** → claim returns 410 `INVITATION_EXPIRED` (cron `affiliates`/admin route marks status `EXPIRED`).
- **OFAC alert in MicroBilt** → never auto-approves; flips deal to manual review.
- **Buyer with active deal** tries to delete account → `409 ACTIVE_DEAL`.
- **Admin token expired (>24h)** → `/admin/*` routes redirect to `/admin/signin`.
